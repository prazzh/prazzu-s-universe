# Prazzh Universe — cross-device viewer names

The website currently has local fallback storage. To make names entered by visitors appear on your phone/laptop too, connect a free Supabase project.

## 1. Create a Supabase project
Create a project at https://supabase.com/ and open its SQL Editor.

## 2. Create the table
Run:

```sql
create table public.bio_viewers (
  id bigint generated by default as identity primary key,
  name text not null,
  time timestamptz not null default now()
);

alter table public.bio_viewers enable row level security;

create policy "public can add viewer names"
on public.bio_viewers for insert
to anon
with check (char_length(name) between 1 and 32);

create policy "public can read viewer names"
on public.bio_viewers for select
using (true);
```

This is intentionally simple for a personal static website. It means someone technically could inspect the public database endpoint. Do not store sensitive information in this table.

## 3. Get your project keys
In Supabase, open Project Settings → API. Copy:
- Project URL
- anon/public key

## 4. Put them in index.html
Find:

```js
const CLOUD_URL = '';
const CLOUD_ANON_KEY = '';
```

Replace the blanks with your Project URL and anon/public key.

## 5. Upload the site
Upload the whole `prazzh` folder to your static host (GitHub Pages, Netlify, Vercel, etc.).

After that:
- Visitor enters a name → it is sent to Supabase.
- Your private ◉ viewer panel fetches the shared list.
- Names are visible across devices.
- Local storage remains as a fallback if the network is unavailable.
